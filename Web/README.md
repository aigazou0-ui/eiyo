# Arcane Direction Battle HTML5

ブラウザだけで遊べる HTML5 Canvas 版の「魔法 × じゃんけん × あっちむいてほい」対戦ゲームです。

## 起動方法

リポジトリルートで以下のどちらかを実行してください。

```bash
npm start
```

または:

```bash
python3 -m http.server 8080 -d Web
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8080/
```

## 操作

- `Enter` または画面上のボタン: ゲーム開始 / リスタート
- `1 / 2 / 3`: グー / チョキ / パー
- `J / K / L / ; / '`: 火 / 氷 / 雷 / 闇 / 光
- `Space`: 現在の選択を確定
- `U`: 攻撃側かつ必殺カウント3/3時に、ガード不可の必殺技を切替

## ルール

1. 戦闘スタートの合図で、最初にじゃんけんをします。
2. じゃんけんに勝った側が攻撃、負けた側が防御です。あいこならもう一度じゃんけんです。
3. あっちむいてほいの合図で、攻撃側は攻撃属性、防御側は防御属性をクリックします。
4. 攻撃属性と防御属性が同じなら、属性ガード成功でダメージなしです。
5. 属性が違えばダメージが通り、攻撃側の必殺カウントが1増えます。
6. 3回ダメージを通すと必殺技が出せます。必殺技はガード不可で、使用後にカウントが0に戻ります。
7. 2ラウンド先取で勝利です。
