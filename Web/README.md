# Arcane Direction Battle HTML5

Unreal Engine 版のプロトタイプ仕様を、ブラウザだけで遊べる HTML5 Canvas 版として実装したミニゲームです。

## 起動方法

リポジトリルートで以下のどちらかを実行してください。

```bash
npm start
```

または:

```bash
python3 -m http.server 8080 -d Web
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8080/
```

## 操作

- `Enter` または画面上のボタン: ゲーム開始 / リスタート
- `W / S / A / D`: 方向選択
- `J / K / L / ; / '`: 火 / 氷 / 雷 / 闇 / 光
- `Space`: 攻撃を確定
- `Shift`: 防御を確定
- `F`: フェイント切替
- `U`: 必殺技切替（ゲージ100%時）

## ルール

- 固定位置のまま中央結界越しに魔法を撃ち合います。
- 攻撃方向と防御方向が一致すると HIT します。
- 方向がズレると BLOCK します。
- 2ラウンド先取で勝利です。
- CPU はプレイヤーの方向履歴と攻撃傾向を読み、次の行動を選びます。
